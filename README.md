# GrabNow — Universal Media Downloader & Engine

GrabNow is a high-speed, modern web video and audio downloader engine supporting YouTube, Instagram, TikTok, Reddit, VKontakte, and 1,000+ platforms without throttling or waitwalls.

## ✨ Features
- **Universal Extraction**: Download video, audio (MP3/M4A), and photo carousels from 1,000+ websites.
- **High Quality**: Supports 4K, 1080p, 720p, and direct stream merging via `ffmpeg`.
- **Live Instagram Harvester**: 1-click sniffer tool to extract locked and multi-slide reels/posts.
- **Bulk & Collection Crawling**: Extract entire profiles, subreddits, and albums.
- **Session Auth & Cookies**: Netscape cookie injection for login-protected content.

## 🚀 Quick Start (Local)
1. Double-click `Start_GrabNow.bat` (or run `node website/server.js`).
2. The website will automatically open at `http://localhost:3000` in Google Chrome.

## 🌐 Deploy to Firebase Hosting
- Double-click `Deploy_To_Firebase.bat` to deploy the web interface to Firebase Hosting.
